# Contributing

This repository is a projection of `dx-corp/mono`. The maintained source is
`products/maestro/vendor/ts-rs-macros-12.0.1` in Mono. Projection updates arrive
as pull requests on `sync/mono-projection`; `.repository-projection.json`
records the source revision.

Please report issues here. Source changes land in Mono and are published by
the projection workflow. The destination owns `.github/**`, `SECURITY.md`,
and this file; the projection owns `macros/**`, `README.md`, and `LICENSE`.
