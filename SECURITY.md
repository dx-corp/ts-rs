# Security policy

Report suspected vulnerabilities privately through GitHub Private Vulnerability
Reporting when available. If the repository does not offer private reporting,
email `security@evalops.dev`, the fallback channel in Mono's security policy.
Include the affected revision, reproduction steps, and impact. Keep exploit
information out of public issues and pull requests while maintainers assess it.

The maintained macro source is in `dx-corp/mono`; fixes flow through its normal
review and projection process.
